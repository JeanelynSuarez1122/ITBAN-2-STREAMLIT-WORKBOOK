" THE EXPLAINATION OF THE ACTIVITY 5 " 

 - For Activity 5, I created a Streamlit app that connects to a MySQL database using SQLAlchemy and provides a secure login system. After logging in, users can select a table from the database to view its contents using `st.dataframe()`. I also included an insert form specifically for the "products" table, allowing users to add new product entries by filling in details like name, description, price, stock quantity, and category. This activity demonstrates how to interact with a database securely, display table data, and perform insert operations within a Streamlit interface.
