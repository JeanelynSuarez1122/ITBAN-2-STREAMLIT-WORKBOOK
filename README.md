" THE EXPLANATION FOR ACTIVITY 2 " 

 - For Activity 2, I created a simple CSV data viewer using Streamlit and Pandas. The app allows users to upload a CSV file using st.file_uploader(). Once the file is uploaded, the data is displayed using st.dataframe() when the "Show Raw Data" checkbox is selected. I also added filtering functionality by letting the user choose a column and a specific value to filter the data using selectbox() components. The filtered results are then shown in a separate dataframe. This activity meets the requirements by showing how to load, display, and filter data interactively using Streamlit components.
