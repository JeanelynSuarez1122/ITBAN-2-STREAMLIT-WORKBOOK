" THE EXPLANATION OF ACTIVITY BASED ON MY CODE AND THE OUTPUT " 

 - For Activity 1, I developed a basic welcome app using Streamlit that demonstrates user interaction and layout styling. I used st.set_page_config() to set the title, icon, and full-width layout of the page. Then I displayed a title and subtitle in the center using HTML with emojis for a friendly touch. The user is asked to input their name and age through st.text_input() and st.number_input(), and when the name is entered, a personalized greeting is shown using st.success(). I also added a footer that says “Made with ❤️ using Streamlit.” This activity meets the requirements by applying core Streamlit components such as input fields, markdown formatting, and basic layout control.
