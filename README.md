" THIS IS THE EXPLANATION FOR ACTIVITY 3 " 
 - For Activity 3 , I created a Streamlit app that dynamically displays different topics using the `st.sidebar.selectbox()` for easy navigation between topics like ETL, Data Lakes, and Data Governance. Based on the user's selection, the content in the main display area is updated using `st.markdown()` to show the explanation for the chosen topic. I organized the content into two columns using `st.columns()`, ensuring a clean and readable layout. This approach allows users to interactively explore each topic, providing an informative and user-friendly experience.
