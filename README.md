" THIS IS THE EXPLAINATION FOR ACTIVITY 4 " 

 - For Activity 4, I created a Crypto Market Dashboard using Streamlit, which displays real-time cryptocurrency data fetched from the CoinGecko API. The app presents various visualizations, such as bar charts, line charts, scatter plots, and pie charts, to represent different market metrics like market capitalization, current price, 24-hour price change, and trading volume for the top 10 cryptocurrencies. These visualizations are created using Plotly and are interactive, allowing users to explore the data in an engaging way. The layout is designed to be wide for better content visibility. The app handles any data-fetching errors gracefully by displaying an error message if the data can't be fetched. This activity fulfills the task requirements by showcasing how to use external APIs, display data tables, and generate different types of charts for interactive analysis.
