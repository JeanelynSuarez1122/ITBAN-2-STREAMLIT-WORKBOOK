" THE EXPLAINATION FOR ACTIVITY 6 " 

 - For Activity 6, I developed a Streamlit application that captures a single frame from the webcam and applies real-time filters and face detection. By using OpenCV, the app detects faces using a pre-trained Haar cascade model and applies Canny edge detection with customizable threshold values via Streamlit sliders. The interface allows users to view the original frame, the frame with face detection, and the Canny edge version, each displayed clearly using `st.image()`. Additionally, users can save any of the three processed images with the click of a button. This activity demonstrates interactive computer vision with a user-friendly layout and snapshot functionality.
